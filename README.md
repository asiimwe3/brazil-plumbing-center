# Brazil Plumbing Center

**Live site:** https://asiimwe3.github.io/brazil-plumbing-center/

Website for Brazil Plumbing Center — plumbing supplies shop on Ruhandika Street, Fort Portal City, Uganda. "Everything you need in plumbing under one roof."

## Features
- Jumia-style shop with search, category filters and an order cart
- Orders are sent to WhatsApp (0752 797 671) — no prices displayed; customers ask on WhatsApp
- Real showroom photos + official logo
- Mobile-first, sticky Call/WhatsApp bar, HardwareStore schema
